# Project Overview

Element is an open-source messaging and collaboration application built on the Matrix network. It provides end-to-end encrypted messaging, voice and video calls, file sharing, rooms, spaces, and communication across different Matrix homeservers.

Element is available for Windows, macOS, Linux, Android, iOS, and the web. The desktop application is based on Element Web and can be configured to connect to different Matrix homeservers.

---

# Messaging & Rooms

Element supports one-to-one conversations and group rooms.

Users can send text messages, voice messages, files, images, and other supported content. Rooms can be organized into Spaces and configured with different permissions and settings.

The application also supports device verification and secure backup features for protecting encrypted communication data.

---

# End-to-End Encryption

Element supports end-to-end encrypted conversations through the Matrix protocol.

Encryption keys and device verification are managed through Matrix's security model, allowing users to verify devices and maintain encrypted communication across supported clients.

Secure backup functionality can help users restore access to encrypted conversation history when moving between devices.

---

# Voice & Video Calls

Element provides voice and video calling for individual conversations and supported rooms.

Calls can be used across compatible Element clients and Matrix deployments, allowing communication without relying exclusively on a single centralized service.

The application also supports sending voice messages directly within conversations.

---

# Matrix & Federation

Element is built around the open Matrix communication standard.

Matrix allows different homeservers and clients to communicate with each other, rather than requiring every user to operate on one centralized server.

Users can connect to the Matrix.org homeserver or configure Element Desktop for another compatible homeserver.

---

# Desktop & Cross-Platform Support

Element Desktop is available for Windows, macOS, and Linux.

Current Windows downloads include separate **64-bit and ARM64** installers. The official package repository shows **Element Desktop 1.12.29** as the current Windows installer dated September 22, 2026.

Element Web provides browser-based access without requiring the desktop application.
